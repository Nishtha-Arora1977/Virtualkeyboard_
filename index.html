How it works

  1. Video stays in your browser — nothing is uploaded.
  2. MediaPipe Hand Landmarker tracks thumb tip (4) + index tip (8).
  3. When the pinch distance < threshold, the key under the midpoint is pressed (400 ms debounce — same as the Python version).
  4. Hover works with mouse or index fingertip.

Why Vercel failed before

The original virtualkeyboard.py is a desktop app: it uses cv2.VideoCapture(0), cv2.imshow, cv2.waitKey and pynput. Vercel's cloud has no webcam, no GUI window, and no long-running while True loop — so it can never deploy as-is. This rewrite runs hand-tracking client-side in the browser, which is exactly what Vercel is designed to host (static files).

Controls

  • Space — add space (max 30 chars, like original)
  • <-- — backspace
  • clr — clear text box
  • Physical keyboard also types into the box
